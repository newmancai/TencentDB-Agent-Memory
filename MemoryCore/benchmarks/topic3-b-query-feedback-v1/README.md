## 方法选择与区别

[ReFIT原论文](https://arxiv.org/html/2305.11744v2)将reranker对当前候选的分布蒸馏到当前查询向量，再检索一次；保持模型参数不变。它说明反馈可作用于可重新检索全库的表示，而不限于旧候选ID。它并不证明跨任务学习或语义置信，也不证明本项目可获得相同收益。

[REPLUG](https://arxiv.org/abs/2301.12652)研究由黑盒语言模型信号优化检索模型；[CONQRR](https://aclanthology.org/2022.emnlp-main.679.pdf)以检索反馈学习问题改写。两者是反馈用途参照，本轮没有复现它们。暂不选生成式改写，避免重回本地小模型输出格式/事实改写故障；也不训练基座检索器内核。

当前提出一个更小且可证伪的假设：先前可信答案使查询embedding发生的变化，是否含有可由问题预测、能跨来源复用的部分。固定一个带单位正则的残差线性映射；同时比较整体均值平移和错配反馈目标，避免把分布平移或模型容量收益归为有效反馈。完整[协议](PROTOCOL.md)已在编码前固定。这是本项目提出的受控开发消融，不是上述论文复现，也不是新的语义真值来源。

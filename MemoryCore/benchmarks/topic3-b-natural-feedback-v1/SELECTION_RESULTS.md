# 固定反馈判断：概率变准是否改善选择？

这是对既有 WildChat 205事件/34会话的事后用途诊断，**不是新数据验证或新学习实验**。不重训、不调用模型、不调阈值、不读原对话改标签。它补齐旧 Brier 改善能否用于选择的证据，不重新开启六维头调参。

## 同一个目标，三种排序

全部事件保持旧 frozen 类别，正确80、错误125。三种分数都回答“这个固定类别是否正确”：原始类别概率、既有LMSYS拟合温度后的同类别概率、既有监督头对同类别的概率。没有改用 learned argmax，避免将分类变化混入置信选择收益。

将事件按分数降序排序，保留前 n 项的错误率为 R(n)=错误数/n。离散 AURC 为 n=1…205 的 R(n) 均值，越低越好；它平均不同覆盖量，不是单一部署成本。另完整保存曲线，列出预先指定25/50/75/100%覆盖（向上取整），没有从曲线选最佳门槛。

| 指标 | 原始分数 | 单温度 | 学习头分数 |
| --- | ---: | ---: | ---: |
| AURC ↓ | 0.45151 | 0.45020 | 0.45237 |
| 判断正确性 AUROC ↑ | 0.6686 | 0.6739 | 0.7112 |
| 保留52项的错误数 | 17 | 19 | 17 |
| 保留103项的错误数 | 51 | 50 | 49 |
| 保留154项的错误数 | 91 | 88 | 83 |
| 保留全部205项的错误数 | 125 | 125 | 125 |

学习头并非完全无用：全局两两排序更好、较高覆盖下少保留部分错误。但AURC没有净优势；保留52项仍错17项（32.69%），不能包装高置信筛选。也不能据此选154项作为部署规则。该指标只涉及反馈行为类别判断，不证明反馈内容为真或记忆归责正确。

按34会话配对重采样1000次、每次重新排序，学习减原始 AURC 的描述性95%区间为[-0.07199,0.08310]；减温度为[-0.06618,0.07879]，均跨零。事件加权而非会话等权，且不含原模型训练和温度拟合的不确定性；旧数据反复使用的限制不能被bootstrap消除。

## 实现与审查

[脚本](selection_audit.py)、[摘要](results/selection-summary.json)、[完整曲线](results/selection-curves.json)。复用既有语义分数、205项预测和既有温度。直接使用 winner-vs-rest log odds 保持概率排序而避免浮点softmax舍入到1；learned缓存概率均严格在0和1之间。三臂均205个不同分数。初版概率排序与此数值修正版摘要完全相同，没有饱和影响本批结果的证据。多类别温度可以改变跨事件排序，不宣称其曲线应完全相同。

独立agent审查固定标签、gold隔离、AURC与会话bootstrap主体通过；补充唯一ID、六维有限logit、正温度检查。未产生新模型采集费用，成本仍依赖旧共享语义采集，不把此次约一秒的CPU重算当在线全流程成本。

```bash
python selection_audit.py --predictions OUT/semantic/predictions.jsonl \
  --scores OUT/semantic-scores.jsonl --temperature OUT/temperature.json --out REPORT
```

沿用原实验numpy/scipy/sklearn环境。当前输入不是运行时反馈契约，仍需经过原适配层；本脚本没有引入MemoryCore接口变化，不重跑无关基座测试。

# 自然反馈：识别有所改善，主要概率收益来自校准

2026-09-13。完成真实用户反馈行为的固定跨来源对照。**没有达到高置信B或可观分类收益；不能凭校准改善宣布主目标完成。** E未参与，无新MemoryCore写入。协议、代码、原始分数与ID级预测均可复核。

## 数据与比较

沿用[公开集适配](../topic3-b-feedback-audit/README.md)与固定版本：108会话438观察、431有效标签，7未知不补NEU。训练LMSYS226事件/73有标签会话，测试WildChat205事件/34会话；剩余1个LMSYS会话无可定位标签。两来源历史已审计，不能说完全未见来源；本次分类器首次固定源迁移评分，未读WildChat逐例错误改规则。

模型输入只有最后两条历史消息和当前用户正文，四个方法同一原文，无未来/标签/来源特征。本批无字符裁剪。六类编号从[官方固定数据卡](https://huggingface.co/datasets/yuhan-nlp/multiturn-feedback/blob/5339f4d77871636030bf4e43ff26b0756cb1fb2d/README.md)核实；NEG_2是有纠正，NEG_3是无纠正，不能按论文正文列举顺序猜编号。真实反馈行为标签不证明用户纠正内容为真，也不证明记忆故障；会话长度不足以替代原题公开长对话主验收。

TF-IDF固定词/字符50000特征+线性分类。冻结语义为Qwen3-4B-Instruct-2507的一次forward六字母分数。学习语义只用同226人工标签拟合六维标准化/线性分类头，测试时冻结；不是few-shot，也不学习记忆失效动作。

LMSYS会话五折OOF：TF-IDF macro-F1 13.14%；冻结语义43.89%、学习44.26%。学习收益在开发也很小，没有依据继续在WildChat改prompt/正则/阈值追分。训练NEU120/226，测试37/205，确有类别占比迁移；它是风险背景，不是未经消融即确认的全部失败原因。

## 为什么补温度参照

Brier是预定辅指标，降低37.38%初看显著。但语义聚合结果后补的普通温度参照，仅用LMSYS最小化NLL，在事先限定[0.1,10]拟合，T≈9.99995触及上界；没有根据WildChat再扩范围。它已解释 **90.15%** 的冻结→学习头Brier改善。该参照是事后解释性比较，不是额外未见评估，也不声称找到最优温度。

冻结分数在197/205事件给出≥0.8的六类内概率，平均99.54%，实际正确率39.59%。学习头降低这种过度自信，但其≥0.6区间只有39例，不能据此挑一个高置信门槛宣布成功。六字母归一化是受限选择概率，不是反馈正确性的经验置信度；2/431事件的六字母全词表质量甚至低于0.5，仍按预定强制选择协议保留，无后验弃权。

**新认识：** 有可信人工标签且确实发生了参数更新，并不保证反馈识别显著改善；低维学习可能主要纠正读出分数，而没有补足区分反馈行为的语义信息。上述90.15%只是数值对照，不是因果分解，Brier同时受概率校准和区分能力影响。这里语义优于词面是预训练能力收益，不能全算成B自优化成果。将信号拆成“实际观察、行为判断、事实/归责验证”仍必要；当前只验证第二层。

## 成本与检查

TF-IDF五折4.21s、全量拟合0.73s、205测试推理0.32s（CPU）。共享语义采集431次forward、218360输入token、无生成token、无失败，GPU forward合计36.69s，p50/p95=70.93/143.04ms；不含加载/分词，不作端到端部署时延承诺。学习头五折0.033s、最终拟合0.0059s、205推理0.00045s，主要成本仍是共同语义采集。全部自有进程已退出，未操作他人GPU。

已验证431个语义输入与同原文适配完全一致且无标签/来源字段；保存的学习头重载复现205预测；两语义分数从预测重算一致。独立agent审查训练折预处理、标签隔离、指标与配对实现，未发现实质评分错误。首次JSONL读取误用splitlines遇到正文Unicode行分隔符，在任何训练前失败；改为逐物理行读后运行成功，未丢样本。未改运行时，沿用之前native合同证据，不重复跑无关全库测试。

## 停止边界与后续

停止将本六类分数校准配置包装成高置信反馈识别；不在205例继续改标签、示例或阈值。不据一次固定词面配置否定所有线性方法，也不据一个六维头否定所有反馈学习。重启需改变可辨识监督对象或证明输入表征缺口，不能只是继续变软概率。

下一机制诊断应只在开发源区分“局部可见证据足够但模型错”与“标签需要更远历史/行为类别本身混淆”，再决定是否改变反馈单位；不直接扩E或开始新的全状态重建。主目标继续active，商用/长编程泛化与完整可移植PR未完成，远端PR未更新。

[独立复盘](INDEPENDENT_REVIEW.md)建议另做开发OOF的温度+类别偏置头，以进一步归因完整头优势。该建议合理但暂不执行：现有温度参照已足以否定“Brier大幅下降就是语义反馈学习成功”的主张，再拆校准头不能解决当前24/39非负反馈被误报的问题。优先审查监督对象和可见证据；不是宣布所有校准路径已达理论上限。

## 复跑

先按feedback-audit README产生ADAPTED。基线环境含scikit-learn1.7.2/numpy2.2.6/scipy1.15.3；模型环境torch2.5.1/transformers4.57.6。本轮两套环境隔离，可在兼容同一环境运行以下命令。

```bash
python run.py --data ADAPTED --out OUT
python semantic.py --tasks OUT/semantic-tasks.jsonl --model LOCAL_QWEN_PATH --out OUT/semantic-scores.jsonl
python semantic_score.py --data ADAPTED --scores OUT/semantic-scores.jsonl --out OUT/semantic
python temperature.py --data ADAPTED --scores OUT/semantic-scores.jsonl --out OUT/temperature.json
```

模型路径指Qwen3-4B-Instruct-2507本地权重，semantic.py需要CUDA；原文/训练模型只存本地，不加入PR。结构化入口：[TF-IDF](results/tfidf-summary.json)、[语义](results/semantic-summary.json)、[温度](results/temperature.json)、[采集](results/acquisition.json)。保存的431原始六分数支持无需GPU复算后两项。

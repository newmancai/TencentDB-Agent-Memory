# SDPO 对 B 的适用边界与最小可证伪迁移

本次只读官方论文与源码；未运行模型或修改实验。结论：可借用“真实后续原话引起的分布差”作为 B 候选反馈信号，不能直接把论文算法接成记忆策略学习器，也不能从六分类失败推断它必然有效。

## 已核验的一手机制

[论文 §3、式(1)、Table 1](https://arxiv.org/html/2603.12273#S3)在同一原回答、同一回答 token 前缀上，比较有/无 hindsight 用户消息的逐 token log probability。它是对原回答的 teacher-forcing 打分，不是比较两次自由生成的答案；后续消息被明确放进 hindsight 模板，不充当原时刻可见信息。式(2)–(3)将信号用于语言模型策略更新，关于隐含 reward 的解释依赖理想化假设。

实际核验源码 revision `3b17d2a67bd2565b9fbda495fd16a485406aa954`：[offline_sdpo_trainer.py L194–228](https://github.com/lasgroup/user_interactions/blob/3b17d2a67bd2565b9fbda495fd16a485406aa954/offline_sdpo/offline_sdpo_trainer.py#L194)。有/无反馈两路都使用同一 `completion_ids`；hindsight 路不求梯度；差值 detach 后乘原 log probability，按有效回答长度平均。不能据函数注释声称还实施了逐序列信号去均值：该段实际没有相减均值操作。[官方信号分析脚本 L538–546](https://github.com/lasgroup/user_interactions/blob/3b17d2a67bd2565b9fbda495fd16a485406aa954/auxiliary/sdpo_signal_analysis.py#L538)另比较相关与无关 follow-up；[论文 §4.3](https://arxiv.org/html/2603.12273#S4.SS3)相关解释主要依靠 24 个交互的定性可视化，不是已证明的自然记忆故障识别性能。

## 合法接点与不能跨越的推断

B 可以把该差值封装成“用户原话对既有回答片段的支持发生怎样的变化”，附回答 span、用户原文引用和不确定性。它比六类行为名更接近反馈内容，但仍是模型的后见反应，不是用户纠正事实的真值，更不是检索/记忆根因。明确记忆 ID 的回答引用也只提供关联；不能把该 span 的负分直接分配给记忆条目。

本项目若只更新有界的记忆消费策略，原论文的 token policy-gradient 等价关系不再自动成立：token 不是检索/消费动作，用户对一个实际回答的反应也不是对所有候选动作的反馈。现有 LMSYS/WildChat 三元组没有本系统实际记忆动作、动作概率或反事实结果，只能先检验信号，不能只凭固定日志宣布记忆策略学习收益。整个回答的分数平均还可能稀释局部反馈；单词概率变化可能仅由复述、词汇启动或风格提示引起。

## 只推进一个有界假设

假设：在用户偏好确实可跨任务复用、且系统记录了实际记忆消费动作时，原始 follow-up 的局部分布差信号能帮助一个小策略头决定何时使用既有偏好记忆，并在之后不再看到该次 follow-up 的任务上超过普通上下文使用。这是待验证的 SDPO 启发迁移，不叫 SDPO 复现，也不以发现记忆故障为目标。

最小实验把候选与记忆正文完全固定，只保留“把既有偏好条目加入回答上下文/不加入”两个消费动作；不新增抽取、状态重建或 E 写入。基座回答模型冻结，唯一学习参数是这个二选一策略头。用少量预先定义的受控用户偏好和任务，探索期随机执行动作并记录概率；每个实际回答获得针对它的 follow-up，不能把另一个回答收到的原话伪装成该动作的实际结果。受控反馈必须明确标记，不能借 natural 数据名义报告。独立固定的偏好/任务判定只供离线验收，不暴露给 B；它衡量偏好是否得到满足，不判断记忆故障。

训练信号来自同一实际回答的有/无 follow-up 打分；聚合规则在开发前固定，更新仅作用于消费策略头。对于未执行动作，没有真实反馈就不填反事实 reward；固定日志只有已知随机探索与足够动作覆盖时才适合有条件的离线策略评估。最终应实际运行保留任务上的策略，避免只证明拟合自造信号。开发与保留任务按会话隔离；若测试同一用户的后续会话，应明确称个性化迁移而非新用户泛化。

必要对照是一组同信息实验，而非继续换 few-shot：普通 ICL 消费策略获得相同历史反馈和既有记忆、相同窗口及推理机会，但不更新权重；普通反馈条件评分策略使用同一 follow-up、同一模型和同样的两路打分缓存，以后见分数本身而非差分作为学习信号；SDPO 启发策略只改变差分信号。再将训练 follow-up 跨独立任务打乱并匹配 token 长度，作为语义关联的负对照，所有组在保留时都不额外得到训练组专享的原话。报告真实输入 token、两路 forward 与学习成本，不能将更多上下文或额外调用当成机制收益。

事前停止条件：真实配对信号不能优于长度匹配打乱，或学习策略不能超过同信息普通 ICL/反馈条件评分，则关闭该记忆策略迁移配置；不要再调六分类、挑响应片段或据测试修改聚合。即使通过，也只支持这个受控偏好消费策略的反馈学习，不外推到自然反馈正确性或记忆故障归责。目前最关键的缺口是实际动作—回答—后续反馈的可识别链条，而不是缺少更大的分类器。

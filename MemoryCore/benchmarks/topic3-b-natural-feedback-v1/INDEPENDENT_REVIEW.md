# 自然反馈 B 组件结果独立解释

仅阅读两份 summary、temperature.json 和 PROTOCOL.md；未读取 WildChat 逐例、未运行模型、未改策略。本审查是结果可见后的开发解释，不能作为新的保留评估。

当前可交付的是自然用户反馈行为的有界分类组件：实际训练为 LMSYS 73 个有标签会话/226 事件，测试为 WildChat 34 会话/205 事件；另 7 个未知不评分。输入是当前用户原话及前两条消息，输出沿用人工行为标签。它能报告“用户在重述、纠正、指出问题、请求澄清或表达满意”，不能据此断言纠正内容属实，更不能把不满归因为记忆故障。它也不是长历史反馈对象定位或自监督学习闭环。监督来自已有人工标注，E 没有参与。

冻结语义 scorer 的 macro-F1 为 0.3977，明显高于固定 TF-IDF 的 0.0733；但这是预训练语义表示相对本次小样本词面基线的组件差异，不是学习头带来的收益。学习头为 0.4261，accuracy 从 80/205 到 85/205，17 胜 12 负，macro-F1 差的会话 bootstrap 区间 [-0.0269, 0.0774] 跨零。LMSYS OOF 也仅从 0.4389 到 0.4426，20 胜 21 负。尚不能声称稳定的分类学习净收益。测试 POS 仅 2 条，固定六类 macro-F1 中该类仍占六分之一，应连同 support 报告。

主要可见改善是概率分数而非新证据理解：Brier 从 1.1892 降至 0.7446；仅训练一个正温度、不改变任何 argmax，也降至 0.7884，数值上解释约 90.1% 的原始到学习头 Brier 降幅。该比例是事后描述，不是因果分解；Brier 同时受区分能力和概率校准影响。温度约 10，接近既定搜索上界，说明该参照仍受限，不能视为最佳校准下界，更不能据测试结果扩大范围重试。学习头确实改变了类别边界（57 个预测不同），因此也不能说它只是整体变软：NEG_3 F1 从 .0571 到 .2623，但 NEG_2 从 .2500 到 .1967、NEG_4 从 .5349 到 .4835。NEG 聚合 TP/FP/FN/TN 完全相同（136/24/30/15）；这不证明逐事件负类决定相同，但不支持负反馈识别总体改善。负类误报仍为 24/39，不能称高可信告警器。

唯一建议的下一步是“类别偏置是否足够”诊断：只复用 LMSYS 六维缓存与固定 GroupKFold5，在每个训练折拟合一个受限的 temperature + class-bias 头 `softmax(logits/T + b)`，并与同折完整六维线性头比较 OOF。事前固定温度范围、偏置零和约束、正则和训练类权重；完整头沿用原配置，两个可改边界的头使用同一训练标签及类别权重。报告 OOF macro-F1、NEG_2/NEG_3 混淆、Brier 和配对胜负；温度单独作为不改 argmax 的参照。重点检验完整跨类别权重是否比简单类别倾向修正提供信息，而不是寻找最优校准器。这是一个诊断，不是三条新路线，不需要模型 forward、few-shot、E 或 WildChat 逐例。

若完整头不能在该开发诊断中超过受限头，就把目前结果收束为“可迁移的行为表示 + 有监督概率/类别偏置适配”，停止继续堆六 logit 学习器；保留它作为廉价组件和回退候选，不包装为已实现可信记忆反馈。如果开发诊断显示额外辨别价值，只能形成待验证假设，必须另有未用于路线选择的会话评估才能主张收益；本轮不再重用 WildChat 追分。六维头共享原 scorer，新增拟合约 .006 秒，但完整语义成本仍含 431 次 forward、218360 输入 token、回执时长合计约 36.69 秒，不能只报头的耗时。

# B 局部约束提示：未观察到组件增益

2026-09-13。有效结果是 v1 任务、v1.1 缺标指标修正；v2 改题已撤回。E、MemoryCore运行时、生产数据均未修改。该实验没有原生 MemoryCore 写入，不是原题主实验交付完成。

## 结果

| --- | ---: | ---: |
| 开发64题合同判断正确 | 44 | 41 |
| 迁移128题合同判断正确 | 79 | 75 |
| 迁移54正例命中 | 7 | 3 |
| 迁移74负例误报 | 1 | 1 |
| 迁移引用合同弃权 | 5 | 2 |
| 迁移原始布尔判断正确 | 83 | 76 |
| 开发28正例中证据集合exact | 2 | 0 |
| 开发合法TP中任意gold证据命中 | 5/8 | 2/5 |

| 迁移模型生成服务时间 | 56.23s | 61.25s |

迁移配对 local 1胜5负122平，双侧精确配对检验 p=0.21875。不能宣称统计证明 local 普遍更差；但这版配置质量、覆盖和总服务时间均没有支持继续投入的证据。其 p95 局部更低（571.8ms vs 662.4ms），不能用一个尾延迟指标掩盖上述质量损失。普通判断只告警8次，其中7真；小分母87.5% precision伴12.96% recall，不能包装成已达高置信成果。

全384调用有17次引用合同弃权：direct11、local6，都是合法JSON引用了目标末轮自身，没有虚构其他ID。保留严格合同评分，并单独报告原始布尔结果；后者仍direct较好，故失败不全由引用合同解释。没有重试、自动补gold或改prompt追分。

## 受控反馈的实际作用和边界

64开发标签按预设规则选择direct；迁移结果因此等于固定direct，没有学习质量收益。额外学习成本至少包括开发local的32.10s服务时间。policy只表示一个全局臂选择，不具备按证据条件学习的表达能力，因此不能用本结果否定条件化反馈学习。

开关关闭与损坏状态回退direct，最多64反馈、一个选择状态。六个合同测试通过。这个独立研究接口的回退不是MemoryCore生产回退的新增证明，原项目回退证据另见旧版本。

## 失败机制：支持什么、不支持什么

local增加主体、属性、条件及说话者的判断限制；它没有外显中间关系判断。当前输出更少真告警，但不能分辨究竟是条件过严、对象匹配失败还是模型执行能力不足。只修改提示措辞不能代表完成了局部关系机制实现。

开发复核中，普通判断命中的文化影响比较、舞蹈能力陈述被local漏掉；两臂也都漏掉过食物偏好等冲突。引用正确与关系正确须分开。有一条烘焙对话的末轮只是建议，矛盾似乎发生在前一轮，该例存在解释争议；这是助手诊断，不改变官方标签，更不能据单例更改全数据集任务。

独立agent只读审查确认：原始分类差异未被引用合同翻转；任意证据命中应与集合exact分报；当前选择器不能检验条件学习。这些结论只关闭**这版局部约束prompt**，不关闭B的局部证据关系路线。

## 错误路线也计入研究成本

第一版把 human-bot 空证据当完整空gold，错误报告了正例定位0。已保留原汇总并撤回该指标，两臂用同一回执重算为 unavailable；分类和选择不变。

随后助手依据争议例过早把任务改成整段矛盾。重新读取[原论文§3.1](https://aclanthology.org/2021.acl-long.134.pdf)确认官方确实检查末轮，因此停止v2，恢复v1。源证据实际包含末轮ID，之前把归一化后的数组误当原数组也是错误。v2不是方法负结果，不能计作公平提升或泛化。

v1：384次，146936输入/6195输出token，179.24s生成服务时间。撤回v2：105完成案例、210有回执调用，77098输入/3719输出token，104.93s；停止时最多另有2次未落盘调用，实际全成本不能只报有回执数字。已终止自有PID2503352，原v1进程自然退出，未停止他人GPU进程。

## 复跑与后续

依赖本地Qwen3-4B-Instruct-2507及原有PyTorch2.5.1/Transformers4.57.6环境，BF16、SDPA、greedy。模型路径通过CLI传入，数据用官方DECODE包。

1. `python run.py prepare OUTPUT --archive decode_v0.1.zip`
2. `python run.py infer OUTPUT --model MODEL_DIRECTORY`
3. `python score.py OUTPUT`
4. `python -m unittest discover -s . -p 'test_*.py'`

无需模型重算时，步骤1后把results/results.jsonl复制到OUTPUT，再执行步骤3。公开包与抽样规则恢复标签，selection.json可核对192条身份。运行输入只有对话，未包含persona/标注/证据索引。原始来源在工作区.local-evidence/topic3-b-feedback-audit，全部实验回执在.local-evidence/topic3-b-local-v1/v2。

下一步应改变可观察的机制，而非继续同例加约束词：把“候选是否定位到相同事实”与“该关系是否成立”独立测量，或利用后续自然陈述形成可审计反馈。先用开发来源建立可判定的对照，保留本128个human-bot作为已使用数据。公开长对话、MemoryCore接入和真正有收益的反馈学习仍未完成。

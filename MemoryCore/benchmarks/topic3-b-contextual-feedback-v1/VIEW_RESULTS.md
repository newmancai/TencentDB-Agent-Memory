# 完整历史与用户原话：固定表示对照

本轮用户原话组输入减少 **73.25%**、生成耗时减少 **37.77%**；匿名助手语义审查为用户原话 **3 胜 1 负 2 平**。但独立审查认为两组全部输出都只有部分目标覆盖。这里证明了一个较便宜的候选基线，尚未证明可靠反馈推断、反馈学习或主目标完成。

## 协议与复现

来源版本、适配和划分沿用 [README](README.md)，配对含义见 [PAIR_PROTOCOL](PAIR_PROTOCOL.md)。排除初次六题和局部十六事件涉及的全部十个 persona，按 SHA256(`cupid-views-v1:` + persona ID) 选两个新开发 persona，每个取全部三种变体。实际六个 ID 和两个 group 固定在 [selection.json](results/views/selection.json)。它们仍属开发数据；不得称六个独立 persona 或未见来源泛化。全来源标签结构曾被聚合审计，验证侧未用于模型或提示调参。

从 prepare.py 生成的 observations.jsonl 按 selection.json 的 ID 顺序取出六行，即可重建 tasks.jsonl。运行：

```bash
CUDA_VISIBLE_DEVICES=0 python compare_views.py --tasks tasks.jsonl --model /path/to/Qwen3-4B-Instruct-2507 --out new-view-run
```

完整历史组传入全部历史消息；用户原话组只保留 role=user 的消息，保留 session/message ID 与原顺序。两组只见 current_request 和 history，不见 group、split、instance_type、配对对手或隐藏参考偏好。两组共用脚本中的固定提示、greedy 解码、256 新 token 上限、24,000 输入 token 上限；按题交替运行顺序。没有裁剪、失败重试或当前六题的事后提示修改。

两组拥有相同可用来源，但**暴露给模型的信息与实际 token 数不同**。这不是严格等输入预算实验，也不能将质量差值归因于单一的角色归属机制。它也不同于早期 BASELINE_RESULTS 的提示与输出预算，不能与那六题直接拼成前后提升。

## 结果与成本

| 指标 | 完整历史 | 用户原话 |
|---|---:|---:|
| 调用数 | 6 | 6 |
| 输入 token | 63,053 | 16,866 |
| 输出 token（含结束符） | 889 | 733 |
| 累计生成耗时 | 33.993 秒 | 21.154 秒 |
| 输入超限 / 输出截断 | 0 / 0 | 0 / 0 |
| 超过提示 100 词 | 5/6 | 1/6 |

同一进程模型加载 2.733 秒；生成计时包含 CUDA 同步，不是完整系统端到端时延。词数按 Python str.split 的空白分词计算。没有触及硬输出上限不等于满足 100 词指令。无须为修复这项诊断重跑当前六题。

匿名审查者只见完整源文、当前请求、官方目标偏好/checklist 和匿名 X/Y 输出，不见组名或成本。目标覆盖 full/partial/absent 是助手语义意见，**不是官方 grader 准确率**。参考遗漏的额外内容不自动算错；作用域错误须回到源文判断。

解码后用户原话 3 胜、完整历史 1 胜、2 平；十二输出均被该审查者标为 partial。主助手独立先审两题，四份输出覆盖判断 3/4 一致，配对偏好 2/2 一致：对 27179c3d7822ed4484cdd5a2 的用户原话输出，主助手判 full，独立审查者认为未保留“仅限”的排他性而判 partial。两份意见都保留，不将争议强行合并为高置信训练标签。样本只有两个 persona，也不作显著性或总体胜率主张。

## 失败机制与方向修正

1. **用户原话不自动保留反馈强度。** 海洋研究总结的同类任务在 s6/s8 已明确要求科学叙事，两组仍将叙事称作可选项或让旧事实优先要求主导。当前用途可从原文核验，并非缺少 E 失效动作。
2. **语境相近不等于适用范围相同。** 市场顾客沟通要求避免农业术语，餐厅批发却强调技术可信度；把后者写成前者的例外会产生有依据但用错地方的结论。研究日志、伦理提案和研究总结同样不能压成一个统一人物画像。
3. **“偏好某物”与“必须/仅限/禁止”不可互换。** 摘要常保留主题词，却弱化执行约束。只评主题命中或正负情绪会漏掉这个问题。

关闭的具体假设是“仅过滤助手消息便足以可靠恢复当前适用反馈”；没有关闭用户原话路线，更没有触及 B 的方法上限。用户原话保留为较便宜的强基线，完整上下文可能在需要解释指代或反馈对象时仍有价值。本轮不增加 E，不采用新默认策略。

下一假设改变监督对象：从整体人物画像改为**当前请求下，某条原始反馈是否适用、其强度是否被保留**。用公开配对同时观察应改变与不应改变的情况，不以恒不更新刷一致性；新增反馈与普通新增正文需要对照，只有反馈驱动的有界决策变化在新 persona 上胜过冻结策略，才算 B 自优化收益。该假设尚未实现或运行；不在本六题追提示、词表和阈值，也不把一次固定视图过滤称为学习。

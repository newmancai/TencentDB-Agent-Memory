# B 反馈来源与标签审计（2026-09-13）

本轮是数据审计，没有模型推理或优化效果结果。上一目标轮建立路线知识库，本轮从实际公开文件检验其数据前提。未启动 E，也未续跑 v9 改写。

## 可复跑

依赖 Python 与 `pyarrow`（本次 25.0.1）。下载以下文件到同一目录，保留原文件名：

- [人工反馈 dense parquet](https://huggingface.co/datasets/yuhan-nlp/multiturn-feedback/resolve/5339f4d77871636030bf4e43ff26b0756cb1fb2d/data/dense-00000-of-00001.parquet)
- [DECODE v0.1 压缩包](https://parl.ai/downloads/decode/decode_v0.1.zip)，脚本核对官方 build.py 提供的 SHA256。

运行 `python audit.py DATA_DIRECTORY summary.json`。本地原始文件在工作区 `.local-evidence/topic3-b-feedback-audit/`，未把来源对话正文加入 PR。审计输出见 [summary.json](summary.json)。脚本不改标签，也不按审计结果自动删除样本。

## 人工反馈集：适合验证行为识别，不能当记忆归责真值

作者 [官方仓库](https://github.com/lyh6560new/implicit-user-feedback/tree/7b4430988907d7541e7bf7a70a6024acdab5f6df) 链接到该数据。实际 dense 文件 108 会话：LMSYS 74、WildChat 34；分别 227/206 个标签，消息数中位数 6/14、最大 56/24。仅 1/8 会话至少 20 条消息。故不能只因名称含 multiturn，就把整体称为充分的长程记忆验证。

实际 schema 有 conversation、反馈类别和反馈文本，无记忆条目、证据归属或故障原因标签。反馈涉及重述、纠错、澄清等，但行为不自动证明旧记忆错误。该集也不能直接验证零显式反馈路线。

对齐审计发现：157 个 NEU 的反馈文本为空，是占位表示，不是 157 个坏标签。按此解释后，仍有 13 会话需审查：3 个标签数不等于后续用户轮数，另 10 个存在非占位文本不一致。尚未把后者判断为语义错误，可能只是文本截断或编辑。

其中一条编程会话的 7 个标签可以唯一精确定位到用户轮 1、4、5、6、7、8、9；中间两轮未标注。若直接按数组下标 zip，会把后面错误回执归到错误轮次。不能把未标注两轮补成 NEU。剩余异常需先分类，不能看模型结果后挑选可用样本。

## DECODE：适合局部证据关系的组件对照

[官方数据说明](https://parl.ai/projects/contradiction/)提供对话矛盾任务。实际 train/dev/test/human-bot 分别 27,184/4,026/4,216/764；消息数中位数 9/8/8/8。主 train/dev/test 都不超过 18 条消息。包内有 aggregated_contradiction_indices，本次所有索引均落在对应 turn_id 集合内；这仅验证位置合法，不证明语义标签无误。

按 conversation_id 去掉 `#` 后缀统计，dev/test 共享 194 个基础 ID；train 与两者均无基础 ID 重叠。A2T/RCT 与 test 共享 2079/2011 个基础 ID，不能称为独立新会话迁移。基础 ID 交集不直接证明每条文本完全相同；若做会话隔离对比，应核验并按基础会话分组。

该集的矛盾标签不等于时间状态更新，更不是应删除记忆的标签。保留为 B 的“证据关系与定位”组件基线候选；不作为原题唯一主验证。

## 对路线的影响

1. 暂不把真实用户的负反馈直接训练成“记忆有错”。更有价值的中间目标可能是识别其约束/证据是否改变了对某个旧判断的认识。
2. 可以用 DECODE 检查局部关系方法是否连基本矛盾定位都优于同预算普通判断，再到公开长对话验证。若仅短对话有益，只报告组件收益。
3. 延迟反馈路线需要的是后续自然证据对旧判断的支持/反驳，而非用户满意度标签。上述两集均未直接提供这类完整真值，不能拼接成已解决的监督。
4. 下一步先完成反馈文本异常分类和基础会话重叠检查；同时定义一个局部关系的同信息基线对照。只在标签实际支持的断言上评估，不把数据清理升级为新 E 工程。

没有新正收益或路径上限结论；当前证据改变的是数据用途与评估设计。仓库运行时未改，未运行全套运行时测试；已实际执行完整文件审计。

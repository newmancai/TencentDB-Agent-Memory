# 同答案同证据配对：关系排序信号存在

2026-09-13。全量来源结构实核：446对抗题中428能匹配同会话普通题，**原答案字符串完全相同、非空evidence集合完全相同**，形成436条边。8条额外边来自一对多，不是额外独立负题。保留18个没有此类配对的对抗题这一覆盖边界，不把筛后子域代表原全量。

一条相同问题/相同答案/相同引用却相反标签的节点保留为冲突，不作有效监督；80个节点因前200+24题端点暴露排除。无未解析引用命中的匹配节点。剩余每会话固定hash取3对，共30开发对，未按模型分数筛选：实际29对双端完整prompt在4096内，1对整体超限。原始edges/excluded/selection可复跑，未修gold。

## 冻结普通基线实测

完全复用上一普通ABC语义核验prompt/模型，不改为对照选择题；每次只看到一端的问题、相同答案和相同完整引用session，正负及另一问题不进入该次输入。两个独立分数离线组成pair。

- 覆盖29/30对，58单端forward；1对双方共同unknown。
- 正题支持判定29/29，对抗题不足判定24/29，两端同时正确24/29。
- 对29/29，正题的三字母归一化支持分数高于负题；未反向分数或调阈值。
- 新增118821输入token、17.914秒，仅forward；无生成token，21331 exit0，无E/MemoryCore/production。

同答案同来源控制排除了“只是答案词面是否有出处”这类解释，但**不能证明所有关系类型可辨别**：配对分布由官方对抗构造和精确匹配决定，且来源相关、可共享正题。与上一200题/24题任务分布不同，不比较总百分比宣称模型升级。会话已有历史暴露，不称独立来源泛化；上游模型也未获得完整去污染证明。

三字母归一化P(A)只是固定分数，不是已校准正确概率；29/29是配对排序，线上通常没有已知正确的配对问题，不能把它当绝对反馈识别准确率。未重新训练，收益属于受控条件下普通基线可利用的信号，不归为本项目自优化。

## 改变下一路线的insight

之前自由解释偶尔发现错归属、最终标签却不一致；本次用不生成解释的固定普通分数，已经能在该受控配对子域稳定区分相对支持程度。**关系信号存在，尚缺的是部署可得的比较对象与可靠消费方式**。这比继续给生成prompt加提醒更具体，也不需要扩展E。

下一候选方法是：仅从实际可见会话中的实体/事件候选提出替代归属，比较原问题与替代问题的证据支持，形成“需要核验哪项归属”的B反馈。替代对象不能从gold正题或隐藏标签取得；需报告生成候选覆盖、合法性及语义是否改变了不该改变的条件。应同时比较当前普通单端核验、同成本静态比较和反馈更新后的有界比较策略，不能把额外查询的收益当学习。

若实际候选无法恢复有用对照，或同成本普通核验已解释收益，就关闭这项消费路线，不能把oracle正题永久搬进运行输入。新的学习对象可以是比较何时可信/值得核验，但不得在本30对调阈值。当前pair排序接近饱和，不继续优化这一代理指标；重点转为移除oracle对照后的可实现性与独立评估。

## 验证与复跑

独立代码审查确认两端证据/答案一致、标签不进prompt、整对长度限制、单端分类与排序分开。选择的是排除旧端点后的最低可用正题index；多个负题可共用同正题，不按29个独立试验外推置信度。

```bash
python pair_probe.py prepare --source LOCOMO_JSON --previous QUESTION_RUN --recent ATTRIBUTION_RUN --model QWEN_MODEL --out RUN
CUDA_VISIBLE_DEVICES=0 python semantic_probe.py infer --tasks RUN/tasks.jsonl --model QWEN_MODEL --allowed RUN/allowed.json --out RUN/predictions.jsonl
python pair_probe.py score --run RUN --out SCORED
```

prepare只加载本地tokenizer，infer沿用torch2.5.1/transformers4.57.6、BF16/SDPA。发布全结构边、选择标签/排除、分数与结果，不发布完整会话正文。本轮未改MemoryCore运行时，尚未验证B反馈驱动学习或完成原题最终验收；goal active。

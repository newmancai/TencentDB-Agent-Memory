# 答案子主张反馈的可消费性探针 v1

运行前固定。每LoCoMo来源取2题，排除上轮10题审核，按partial-feedback-v1:题ID hash排序；仍历史来源开发，不称从未使用题。取QA top10相对Q top10最高新增候选及前后各一条、日期。选择不读参考标签。20题两臂同原文/答案/模型/256生成上限/4096输入上限，交替臂顺序，不重试或修输出。

普通审核输出relation/evidence_ids/explanation，明确允许解释部分支持；子主张臂输出答案原文span与证据ID及缺失关系，最多3项。后者是反馈表示探针，不是已学习策略。精确span和ID只证明机械对齐，不证明语义。

报告两臂原始结果、合同有效性及全部调用成本。独立语义审核需读普通解释中已有部分支持，不能因为其没有新schema就判劣；同样不能把parts解析成功算语义正确。先固定hash抽样两臂共同可评题最多6项独立审阅，分“有用且正确的答案成分/错误归属或过度支持/缺失”；不能用QA整答gold或参考ID命中自动判子主张。无效输出作为不可消费单列，保留原文，不从解释补parts评分。小样本诊断不估总体precision，不据当前题改prompt/上限。

研究通过条件是出现相对普通解释可核实的反馈价值；仅字段变化不算。若无增量，关闭当前表示配置，不继续格式变体或扩E。即使有组件增量，也尚需后续反馈驱动状态更新、强基线及独立验收。

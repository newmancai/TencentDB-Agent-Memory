# 后见答案增量信息：FTS5基线 v1

运行前固定。LoCoMo所有类别1/2/4、全部证据ID精确解析的1438题；其余6题unknown，类别3/5不作正证据。全是历史研究来源，仅开发诊断。无需模型或新合成问题，不以QA数组顺序模拟自然反馈。

每个会话建立一个SQLite内存FTS5索引，unicode61，文档为单条speaker+text，ID不索引。使用SQLite原生bm25，分数相同按原消息序。不实现或替换基座索引内核。此为基座词面参照，尚非MemoryCore完整融合检索对照。

四臂：Q，A，Q+A，Q+control。A为公开gold在受控反馈阶段揭示的答案，绝非自然用户确认。control取其他会话、与A不完全相同、词数最接近的答案，hash作确定性tie break；可重复取用，不能称一对一匹配。选择control不用evidence或检索成绩。

查询为可见输入的全部Unicode词去重、逐词引号转义后OR，不设stopword、不调权。相同索引、相同每次top10候选上限，报告k=1/5/10，不以事后最优k选配置。候选长度不同，报告字符数和词数；不声称同token预算。词数不是模型token数。

核心只接收documents/query，不读gold。检索全部结束后才计算参考证据any/all recall与macro证据召回；未标注不是负例，不报告语义precision。比较Q+A相对Q的新增/丢失参考证据、any/all逐题胜负。给出各来源结果、实际query耗时p50/p95和索引时间（CPU微基准，非生产端到端）。空查询/无命中保留，不补答案或改gold。

目的仅是确定反馈中的已知答案能提供多少普通词面信息。若有收益，先归因普通后见信息，不能称B学习成功；后续方法须超过同信息Q+A以及A强参照。不按此次错误调stopword、字段权、k或答案截取。全部回执保存以便复核。
